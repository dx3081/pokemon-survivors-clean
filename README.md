# 口袋妖怪幸存者 · Pokémon Survivors

[中文](#中文) | [English](#english)

## 中文

基于 [PokéRogue](https://github.com/pagefaultgames/pokerogue) 制作的宝可梦同人幸存者游戏，免费分享 **Windows 和 macOS 最终版**。

俯视角自动战斗，你负责走位、抓宠和养成。支持中文 / English。

### 下载最终版

- [Windows 下载](https://github.com/dx3081/pokemon-survivors-clean/releases/download/v1.0.0/PokemonSurvivors-Windows.zip)：完整解压后运行 `PokemonSurvivors.exe`，EXE 和 PCK 保持在同一目录。
- [macOS 下载](https://github.com/dx3081/pokemon-survivors-clean/releases/download/v1.0.0/PokemonSurvivors-macOS.zip)：解压后打开 `Pokemon Survivors.app`。
- [查看 Release 页面](https://github.com/dx3081/pokemon-survivors-clean/releases/latest)。

### 从源码运行

使用 **Godot 4.7.2** 打开 `project.godot`，等待资源导入后运行 `main.tscn`。项目包含 Windows Desktop 和 macOS 导出预设；导出时需安装对应版本的 Godot 导出模板。

### 操作

- WASD / 方向键：移动。
- 招式自动释放。
- Esc / Q / E：打开抓宠界面。
- 数字键 1–5：选择精灵球。
- 设置中可切换中文 / English。

## English

A Pokémon fan-made survivor game based on [PokéRogue](https://github.com/pagefaultgames/pokerogue), with the **final Windows and macOS builds available for free**.

Survive top-down battles with automatic attacks while you move, catch Pokémon, and develop your team. Supports Chinese and English.

### Download the final release

- [Download for Windows](https://github.com/dx3081/pokemon-survivors-clean/releases/download/v1.0.0/PokemonSurvivors-Windows.zip): extract the entire archive and run `PokemonSurvivors.exe`. Keep the EXE and PCK files in the same folder.
- [Download for macOS](https://github.com/dx3081/pokemon-survivors-clean/releases/download/v1.0.0/PokemonSurvivors-macOS.zip): extract the archive and open `Pokemon Survivors.app`.
- [View the release page](https://github.com/dx3081/pokemon-survivors-clean/releases/latest).

### Run from source

Open `project.godot` in **Godot 4.7.2**, wait for assets to import, and run `main.tscn`. Windows Desktop and macOS export presets are included. Install the matching Godot export templates before exporting.

### Controls

- WASD / arrow keys: move.
- Attacks trigger automatically.
- Esc / Q / E: open the capture interface.
- Number keys 1–5: select a Poké Ball.
- Switch between Chinese and English in Settings.

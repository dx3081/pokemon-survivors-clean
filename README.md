# Pokemon Survivors

宝可梦版“吸血鬼幸存者”：俯视角，一群野生宝可梦围上来，你的宝可梦自动放招，你负责走位、抓宠、养成。

- 引擎：Godot 4.7.2（GDScript）
- 用 Godot 打开本文件夹，运行主场景 `main.tscn` 即可。
- 操作：WASD / 方向键移动，招式自动释放；Esc / Q / E 打开抓宠界面；数字键 1–5 选精灵球。
- 设置里可以切换中文 / English。
